STEP 6: COMMIT LATEST CHANGES
------------------------------
git add .

STEP 7: DEPLOY TO ELASTIC BEANSTALK
------------------------------------
# Initialize EB (if not already done)
eb init

# Select:
# - Region: eu-north-1
# - Application name: smart-energy-grid-management-system (or your existing one)
# - Platform: Go
# - CodeCommit: No

# Deploy to environment
eb deploy

# This will:
# 1. Package your application
# 2. Upload to S3
# 3. Deploy to Elastic Beanstalk
# 4. Build the Go binary using Buildfile
# 5. Start the app using Procfile

STEP 10: TROUBLESHOOTING
-------------------------
If pages still show wrong content:

1. Check EB logs:
   eb logs --all

2. SSH into instance:
   eb ssh
   
3. Check if templates exist:
   ls -la web/energy-dashboard/templates/
   
4. Restart application:
   eb restart

5. Check environment variables:
   eb printenv

6. Set missing environment variables:
   eb setenv AWS_REGION=eu-north-1

COMMON ISSUES & FIXES:
----------------------
Issue: "API offline" status
Fix: Check AWS credentials in environment variables

Issue: Empty equipment/alerts
Fix: Verify DynamoDB tables exist and have data:
   - Run populate-correct-tables.go script
   - Check AWS region matches (eu-north-1)

Issue: Template rendering errors
Fix: Ensure all template files are committed to git

Issue: Build fails
Fix: Check go.mod dependencies and Go version (1.22+)

ROLLBACK PROCEDURE:
------------------
If deployment fails:
1. eb abort                    # Abort current deployment
2. git revert HEAD            # Revert last commit
3. eb deploy                  # Deploy previous version

Or restore from EB console:
1. Go to Elastic Beanstalk console
2. Select application
3. Application versions
4. Deploy previous version
